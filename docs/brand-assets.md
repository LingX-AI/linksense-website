# Website brand source

The website uses the original LinkSense vector paths from the approved Figma file, exported on 2026-11-20.

- File: https://www.figma.com/design/GIy53t29UhECq6RxUx2CbA/Linksense
- Source frame: `1:146744`, sidebar shared brand, original vector frame `I1:146745;1:7674;1:7934;76:7280`.
- `public/brand/figma-lockup-light.svg`: unmodified SVG export of the original paths.
- `public/brand/figma-lockup-dark.svg`: identical paths; only the wordmark fill changes from `#1B1D20` to `#F4F7FC` for contrast.
- `public/brand/figma-icon.svg`: the two original icon paths, with the view box fitted to their bounds. No paths were redrawn.
- Primary brand blue: `#1866E1`; hover blue: `#1256C3`. Neutral body ink: `#1B1D20`.
- The header, footer, favicon, and social sharing card use these source assets. The team showcase and closing action omit decorative logo repetitions.

The CSS brand primitives feed the semantic action, accent, and surface colors. Dark mode uses lighter blue accents and light text; green remains reserved for spreadsheet affordances and amber for the open-source star.
